# ROADMAP — 版本范围与后续方向

- [x] 真实外部检索（DDG，Provider 可插拔）

- [x] 决策理由与效果反馈全量轨迹（含证据清单）
- [x] 可复现示例任务 ×3 + 离线回放验证
- [x] 离线单元测试 43 个（含重试状态语义与回放还原）

## v0.1 — P1（P0 验收后推进；仍在 v0.1 版本范围内，不升级 v0.2）

实施简报见 [P1_BRIEF.md](P1_BRIEF.md)。

- [ ] **语义证据整理与融合**：本地嵌入模型替换/增强词法相关性；证据聚类与冗余压缩；对比实验（词法 vs 语义评价器的停止点差异）
- [ ] **Working Memory**：当前任务内证据与决策的滑动窗口，供评价器直接消费
- [ ] **Episodic Memory**：历史任务轨迹的存取接口（任务名→轨迹/效果摘要）
- [ ] **Long-term Memory 基本接口**：跨任务策略参数（K、阈值、策略选择倾向）的持久化读写
- [ ] **评测集扩展**：10+ 任务（含不可满足任务真实触发 diminishing/forced 路径）+ 自动评分脚本

## 后续研究方向（v0.1 不承诺）

- 元元认知：对评价器本身可靠性的监控与校准（何时该信自己的充分性判断）
- 跨任务策略演化：以 Episodic/Long-term Memory 驱动策略参数与策略族的选择
- RSI 相关探索：反馈信号驱动的策略自改进实验

## 原则

- 规划中能力不得描述为已实现；每项能力以可运行、可复现、可查证的交付为准。
- 版本号保持 v0.1，直至 GPT 正式验收并规划下一版本。
